# Requirements
- An Internship Application Tracker built for second-year university students in Computer Science

## Functional Requirements
### Essential
- The user can register and log in
- The user can only see/edit their own applications
- The user can log out and delete their account

- The user can add an application with relevant details
- The user can edit/delete an application
- The user can set a status (e.g. Applied, Interview, Rejected, Withdrawn)
- The user can record a deadline for each application

- The user can see all applications in a list/table
- The user can filter by status
- The user can search
- The user can sort by date

- The user can see summary counts (total applied, interviews, offers, rejections)
- The user can see upcoming deadlines highlighted
- The user can export applications to a CSV
- The user can attach a CV or cover letter to an application

### Optional
- The user can add notes to an application
- The user can record salary, application source, and a contact person
- The user can opt in to email reminders
